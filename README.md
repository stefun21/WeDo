WeDo — Better Together

WeDo is a friendly shared space that helps couples, families, friends, and small teams stay organized together. Create groups, manage collaborative tasks, organize shopping lists into custom folders, chat in real time, mention members, assign responsibilities, and receive notifications—all from one clean and intuitive app.

Built as a responsive PWA, WeDo works smoothly across desktop and mobile, can be installed like a native app, and keeps everyday collaboration simple, organized, and enjoyable.

Designed and built with a little creativity, a lot of iteration, and plenty of vibe coding. 💚
